## 📖 Story & Overview

**Problematic Silence** explores a world shaped by fear, unresolved tension, and unspoken words. Navigate through eerie levels, collect lost relics, interact with **YAAR**, and uncover the mystery behind the silence.

- **Engine:** Pure HTML5 Canvas & Vanilla JavaScript (Zero external libraries)
- **Audio:** Real-time procedural sound synthesizer using Web Audio API
- **Responsive:** Auto-scales across mobile screens, tablets, and desktop displays

---

## 🕹️ Controls

| Action | Desktop Keyboard | Mobile / Touch Screen |
| :--- | :--- | :--- |
| **Move Left / Right** | `A` / `D` or `◀` / `▶` | On-screen Left / Right buttons |
| **Jump** | `W` / `Space` / `▲` | On-screen **▲** button |
| **Interact (YAAR)** | `E` key | On-screen **YAAR** button |

---

## ✨ Features

- **Dynamic Atmospheric Lighting:** Real-time canvas shadows and entity glow effects.
- **Particle System:** Custom dust and interaction particles on jumping, running, and relic collection.
- **Persistent High Scores:** LocalStorage integration to save and track your personal best scores.
- **Touch Layer:** Virtual D-pad and action triggers automatically tuned for mobile browsers.
